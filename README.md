# اعرف ربك

تطبيق عربي، يبدأ من الجوال، للتعلّم عن أسماء الله وصفاته من مصدر يمكن الرجوع إليه. التجربة سؤال قصير ثم توسّع، لا فهرس موسوعي.

## المصادر

المحتوى الديني المعروض مبني على كتاب **أصول الإيمان في ضوء الكتاب والسنة** (نخبة من العلماء، وزارة الشؤون الإسلامية، الطبعة الأولى 1421هـ). كل بطاقة تحمل صفحة ونصًا منقولًا، والصياغة المبسطة مفصولة عن نص الكتاب ومُعلَّمة بذلك.

الدرر السنية لا تُخزَّن مسبقًا. البحث الحي يمر عبر الخادم:

`GET /api/dorar/aqeeda?q=`

ويطلب `https://dorar.net/api/v1/aqeeda/search` بالرمز الموجود في البيئة فقط. إذا تعذر المصدر تظهر: «تعذّر تحميل المصدر حاليًا.» ويبقى نص الكتاب.

لا يُولَّد حكم عقدي إذا لم يرجع مصدر معتمد.

## التشغيل

```bash
npm install
npm run icons
cp .env.example .env.local
npm run dev
```

ضع رمز الدرر في `.env.local`:

```
DORAR_API_TOKEN=
```

لا تستخدم `NEXT_PUBLIC_` مع هذا الرمز.

النسخة الأولى فيها 12 مادة مراجعة من باب الأسماء والصفات، للتمثيل لا للحصر، كما يقول الكتاب نفسه.
